Instructions

How the app should work

This preserves the workbook workflow while giving you a clear order for implementing the JavaScript.

User workflow

1

Setup

Enter height, weight, age, gender, workout days, goal, and macro preference. Calculate BMR, maintenance, target calories, and macro grams.

2

Add foods

Enter each food once with serving size in grams, calories, fat, carbs, and protein.

3

Pick a date

The daily summary should only total food-log entries that match the selected date.

4

Choose goals

Either pull goals from Setup or use manual daily calorie and macro goals.

5

Log food

Select a food and enter grams eaten. Scale the saved serving nutrition to the amount eaten.

6

Check remaining

Show consumed, remaining, and percentage of each goal used.

Suggested JavaScript build order

No answers included
  1. DOM basics: select the Setup inputs and output elements, then respond to the #calculate-goals button.
  2. Calculator: implement BMR, activity multiplier, cut/maintain/bulk adjustment, and macro gram calculations.
  3. Objects & arrays: represent each food as an object and keep all foods in an array.
  4. Rendering: create a function that turns the foods array into rows inside #foods-table-body.
  5. CRUD: add food creation, editing, deleting, and search filtering.
  6. Persistence: save Setup values and food data in localStorage.
  7. Food logging: calculate nutrition using amount eaten ÷ serving size × serving nutrition.
  8. Daily totals: filter log entries by date and use reduce() to total calories/macros.
  9. UI state: update remaining values, percentages, and progress bars automatically.
  10. Weight: save weigh-ins and build the points string for #weight-line.
  11. History: group food-log entries by date and render a daily summary for each date.
  12. Refactor: split the code into modules such as storage, calculations, rendering, and page-specific logic.
Maintenance note from the spreadsheet: workout days alone cannot perfectly determine maintenance. Steps, job activity, workout intensity, and individual metabolism matter. Treat the estimate as a starting point and compare it with 2–3 weeks of weight trend.
